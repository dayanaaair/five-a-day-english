# Five a Day · English with Diana

100 тематических блоков по 5 английских выражений: 500 чанков с постепенным переходом от A1 к A2.

Карточки, поиск пар, выбор перевода, сборка фраз, пропуски в контексте, письменный перевод, работа над ошибками и подготовка трех фраз к разговору.

Прогресс сохраняется в браузере. Доступны экспорт и импорт резервной копии. Расписание занятий и даты уроков не задаются.
